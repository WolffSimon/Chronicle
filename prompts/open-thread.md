# Opening a thread

Paste this as the first message of each thread's first chat. Replace the bracketed parts.

```text
This is the [thread name] thread. Before anything else, read
[folder]/Thread_Context.md in the project files and follow its reading order.
Read master/House_Style.md in full, then the thread log and the record
extract. Then read the running list as section 6 describes.

If this chat already holds conversation with me about this area, write into
[folder]/Thread_Log.md every fact, decision and open item from it that the
folder lacks, dated and in my words, with sensitive lines marked PRIVATE.

When you have done that, tell me in a few lines what is coming up in the next
fortnight, and put the section 11 questions to me, numbered.
```

For later chats in the same thread, a shorter version is enough:

```text
[Thread name] thread. Read [folder]/Thread_Context.md and follow its reading
order, then carry on.
```
