# Handing over a thread

Paste this in a thread's chat when the thread retires, merges into another or moves to a new chat because its context is full.

```text
This thread is handing over to [successor]. Write
[folder]/Operating_Guide_[today].md from templates/operating-guide.md, for
the chat that takes over.

It should let a chat that has never seen this conversation do the job on the
first day: where everything lives, how to read and write the list, the id
scheme and the next free ids, the fields, what I have said never to track,
how I report, the etiquette, open questions, and the cross-thread joins.
End it with a snapshot of the full state now.

Then write a last log entry recording the handover, and tell me in one line
where the guide is.
```
