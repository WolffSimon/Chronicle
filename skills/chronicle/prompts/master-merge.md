# The master merge

Paste this in the master chat, weekly or whenever the logs have moved a lot. It folds the thread logs into the canonical documents.

```text
Run the master merge.

1. Read every thread's Thread_Log.md entries since the last merge (the date
   is in master/Master_Log.md).
2. For each new fact about me, propose a change to master/Record.md. For each
   new person or change to a person, propose a change to master/People.md.
   Keep my words where I gave them. Carry the PRIVATE marker across: a private
   fact goes into the canonical document only if it belongs there, and is
   marked private there too.
3. Show me the proposed changes as a numbered list, grouped by document.
   Wait for my answers. Then make the changes I accept.
4. List any contradictions between threads, and between a log and the
   project instructions. Do not resolve them yourself. Put them to me.
5. List anything in the project instructions that the logs show is out of
   date, and propose the edit.
6. Record the merge in master/Master_Log.md with the date and what changed.
```
